- **Fineract Loan Origination:** substantial inherited Java backend, customer/staff frontend and workflow/scoring/integration foundations. [Source](https://github.com/apache/fineract-loan-origination), Apache-2.0.
- **Fineract Business Intelligence:** inherited extraction, PostgreSQL warehouse, dbt models and Superset dashboard foundations. [Source](https://github.com/apache/fineract-business-intelligence), Apache-2.0.
- **Angular, TypeScript, RxJS and the npm ecosystem:** frontend runtime and tooling. Applicable licenses remain with the packages and generated third-party license output.
